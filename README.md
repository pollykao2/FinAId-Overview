# FinAId 智財幫
財務社工個案與財務資訊管理系統

## Project Overview

FinAId 是五人團隊共同開發的畢業專題，針對財務社工在個案資料、
收支紀錄及訪談內容分散管理的問題，整合個案管理、財務資訊與
AI 輔助功能，支援個案追蹤與資料整理。

專案透過與產學合作單位及財務社工交流，將實務需求轉換為系統功能。

## Key Features

- **個案資料管理**：建立、查詢與維護個案基本資料及相關紀錄。
- **財務紀錄管理**：管理年度與每月收支，以及投資、保險等資訊。
- **收支視覺化**：透過圖表呈現個案財務變化。
- **訪談紀錄整理**：提供語音轉逐字稿與摘要功能。
- **補助津貼查詢**：以查詢機器人協助查找補助條件與申請資訊。

## System Architecture

| 層級 | 技術與職責 |
| --- | --- |
| 前端 | Next.js，提供操作介面與資料呈現 |
| 後端 | Java Spring Boot，處理業務邏輯與 API |
| 資料庫 | MySQL，儲存個案與財務等結構化資料 |
| AI 功能 | 語音轉錄、訪談摘要與補助查詢 |

## My Contributions

擔任專題組長，負責工作分配、進度追蹤，並參與系統開發與文件撰寫。

- **後端開發**：個案年度與每月財務資料的查詢、新增、修改與刪除功能。
- **圖表功能**：參與個案收支統計圖表的前後端開發。
- **介面設計**：參與註冊、登入及多項個案資料表單的 Figma 設計。
- **團隊協作**：協調成員分工與開發進度，整理專案文件。

以上為個人負責項目；完整系統由團隊共同完成，
AI 模組由其他團隊成員負責。
